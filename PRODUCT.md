# Nightshift Desktop

Nightshift is a personal, native GTK desktop dashboard and appearance toolkit for Zorin/GNOME 46 on X11. It helps its user keep useful information and small actions on the desktop: time, local notes/tasks, system readings, optional service insights, media controls, and application shortcuts.

## Confirmed product constraints

- Preserve the existing transparent midnight/RGB appearance, monoline drawings, movable/resizable widgets, saved arrangements, and reduced-motion support.
- Preserve Super+D and Super+Arrow bindings and unrelated desktop/application settings.
- Personal content stays in the user profile. The public repository and previews contain no connected accounts, tokens, personal notes, photos, or session data.
- Integrations are optional, errors must be visible, and cached or reference material must not be presented as freshly published data.

## AI Learning

The learning widget helps the user find practical AI techniques to try, especially chatbot cost savings, latency, inference optimization, agents, and retrieval. It checks official feeds and article indexes from OpenAI, Anthropic/Claude, n8n, Google AI, Google Developers, Google Research, Hugging Face, Cloudflare, and NVIDIA every five minutes. It selects relevant recent articles and shows publisher excerpts and dates. Reference guides have an explicit Guide label. Save buttons remain usable, report duplicates without adding another copy, and allow saving again after removal.

The user can filter by Cost, Latency, or Build and search resources locally. The explicit Web button opens a broader AI query in Google. Suggested experiments are derived from a resource’s topic, not asserted performance guarantees or model-generated article summaries.

To-do saves an experiment with its source URL. Notes appends a takeaway, suggested experiment, and source to the current text. Both preserve existing content, including unfinished edits, and avoid duplicate saves of the same source. A separate Google shortcut opens Google and follows the existing layout and resize controls.
